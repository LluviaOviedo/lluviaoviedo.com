# lluviaoviedo.com

Portafolio profesional de Lluvia Oviedo (ES en `/`, EN en `/en/`). Sitio estático, sin dependencias.

- Editar textos: `build.py` (diccionario `CONTENT`) y luego ejecutar `python3 build.py`.
- Estilos: `assets/style.css` · Interacciones: `assets/main.js`.
- Publicado con GitHub Pages; DNS en Cloudflare.
